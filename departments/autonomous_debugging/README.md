# Autonomous Debugging

**Estado:** IMPLEMENTAÇÃO INICIAL 0.5.0–0.5.4; investigação, classificação, reprodução, comparação de propostas e memória. Execução real de jogo permanece nos laboratórios existentes.

## Mandato

Identificar, localizar, reproduzir, formular hipótese, corrigir, testar, comparar, preparar PR e registrar.

## Restrições

Até 2 candidatos por investigação; sem execução automática de código arbitrário ou merge no jogo.

## Entrega e aceitação

Relatório, teste e PR revisável. Toda entrega exige hipótese, critérios prévios, revisão exata, evidência e limitações. Consulte [protocolo](../../docs/RESEARCH_PROTOCOL.md). Não assumir integração automática.
