# Scientific Knowledge Registry

**Estado:** implementação mínima em engineering_lab; não homologada até CI.

## Mandato

Planos, resultados, hashes, fontes, versões, maturidade e evidência.

## Restrições

Sem duplicar catálogo Foundation; sem aprovação automática.

## Entrega e aceitação

Registro local funcional inicial; autenticação e adapters pendentes. Toda entrega exige hipótese, critérios prévios, revisão exata, evidência e limitações. Consulte [protocolo](../../docs/RESEARCH_PROTOCOL.md). Não assumir integração automática.
